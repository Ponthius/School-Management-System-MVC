SCHOOL MANAGEMENT SYSTEM - QUICK COMMANDS
(run everything from the folder containing "School Management System.csproj")

--- 1. CONNECTION STRING (appsettings.json) ---
"DefaultConnection": "Server=POEL-WORKSAPCE\\SQLEXPRESS;Database=SchoolManagementDB;Trusted_Connection=True;TrustServerCertificate=True;Encrypt=False;MultipleActiveResultSets=true"

--- 2. ONE-TIME SETUP ---
dotnet tool install --global dotnet-ef
dotnet restore
dotnet build
dotnet ef database update

--- 3. START SERVER ---
dotnet run
(or hot reload:)
dotnet watch run

Open: http://localhost:5168   or   https://localhost:7277
Login: admin / admin123
Stop:  Ctrl + C

--- 4. AFTER CHANGING A MODEL ---
dotnet ef migrations add NameOfChange
dotnet ef database update

--- 5. DATABASE RESET (DELETES ALL DATA) ---
dotnet ef database drop
dotnet ef database update

--- 6. OTHER USEFUL ---
dotnet --version
dotnet ef migrations list
dotnet ef database update PreviousMigrationName
dotnet ef migrations remove
dotnet dev-certs https --trust

--- QUICK FIXES ---
Can't connect to server  -> check server name above (double \\ in JSON), start SQL Server (SQLEXPRESS) in services.msc
Cannot open database     -> dotnet ef database update
dotnet ef not found      -> dotnet tool install --global dotnet-ef (reopen terminal)
Port in use              -> change applicationUrl in Properties/launchSettings.json
HTTPS warning            -> dotnet dev-certs https --trust

--- HOW IT FLOWS (SHORT) ---
Login (/Account/Login) -> checks Users table -> saves role in session
  Admin   -> /Dashboard/Admin   (students, teachers, classes/subjects, attendance, exams, results, payments, calendar, settings)
  Teacher -> /Dashboard/Teacher (classes, attendance, marks, materials, assignments)
  Student -> /Dashboard/Student (results, fees, schedule, materials, notices)

First-time data order (admin): Classes & Subjects -> Teachers -> Students -> Exams -> Calendar -> Payments

Create the classes first, then the teachers, then the students. This comes from how the code handles each one.

What each one depends on

Class: a class can be created with no teacher. Class.TeacherId is optional, so it has no dependency on anything.
Teacher: if you tick “is class teacher”, the form requires you to pick an existing class. If you don’t, it shows “Select the class this teacher heads”. The primary class is optional. The subject checkboxes come from the Subjects list, and the form says “Add subjects first” if that list is empty.
Student: a class is required. ClassId is not nullable and the form validates it. A teacher is not needed.

So classes and subjects have to come before teachers, and classes also have to come before students.

Recommended order

Subjects (Classes & Subjects page): create these so the teacher form has subject checkboxes to pick from.
Classes (same page): create them without a teacher.
Teachers: while creating each one, tick “class teacher” and pick the class they head. That assigns them in one step. Alternatively, use the Assign Teacher button on the Classes & Subjects page later.
Add subjects to each class (Classes & Subjects page).
Students: pick their class in the form.
After that, create the exam terms and schedules, then attendance, results and payments.
